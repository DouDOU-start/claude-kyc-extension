Claude KYC 浏览器扩展

系统要求
  Windows 10/11
  Chrome、Edge 或其他 Chromium 浏览器

首次安装
  1. 解压安装包。
  2. 双击“安装.cmd”。
  3. 安装器会打开扩展目录，并显示需要加载的完整路径。
  4. 打开 chrome://extensions 或 edge://extensions。
  5. 开启“开发者模式”。
  6. 点击“加载已解压的扩展程序”。
  7. 选择安装器输出的 extension 文件夹。

  正确的目录通常是：
    %LOCALAPPDATA%\ClaudeKYC\extension

  不要选择：
    %LOCALAPPDATA%\ClaudeKYC

使用
  1. 点击工具栏中的 Claude KYC。
  2. 填写代理 IP。
  3. 填写 Claude 网页 SK（sessionKey，不是 Anthropic API Key）。
  4. 组织 ID 可选；不填时自动读取，填写后直接使用该组织。
  5. 点击“查询 KYC”。
  6. 需要验证时点击“获取验证链接”，复制链接后在浏览器中完成 Persona 验证。
  7. 完成后回到扩展点击“刷新状态”。

代理格式
  http://主机:端口
  https://主机:端口
  socks5://主机:端口
  socks5h://主机:端口
  主机:端口
  主机:端口:用户名:密码

  {session} 和 {region} 会在每次查询时自动替换。
  留空表示直连。

自动更新
  扩展每天最多自动检查一次 GitHub Releases。
  发现新版本后，扩展顶部会显示更新提示；点击一次即可下载、校验并更新。
  自动更新仅在扩展从安装器目录加载时启用。

隐私
  SK 只保存在当前标签页的会话存储中，关闭标签页后清除。
  代理地址保存在扩展本地存储中。
  查询由本机查询器直接连接 Claude，不经过第三方服务器。
  更新请求只访问本项目的 GitHub Releases。

常见问题
  “Manifest file is missing or unreadable”
    选择错了目录。请选择 ...\ClaudeKYC\extension 本身。

  “本地查询组件未安装”
    重新双击“安装.cmd”，然后重新打开扩展页面。

  “Claude 要求浏览器验证”
    代理出口被 Claude 拦截，请更换住宅代理后重试。

  “Claude 拒绝了这个 SK”
    检查 SK 是否过期、账号是否一致。

  “Claude 未提供此组织的 KYC 状态”
    检查组织 ID 是否属于当前 SK 对应的账号。

卸载
  1. 在扩展管理页移除 Claude KYC。
  2. 双击“卸载.cmd”。
